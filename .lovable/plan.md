# Import ElevateX Command Center from GitHub

Bring the public repo `muhammad1hamid/elevatex-command-center` into this project so it runs here as its own app with a fresh backend.

## What gets imported

- Full app source: auth screen, authenticated shell with sidebar + global search, and all pages (overview, daily mission, weekly review, leads + lead detail, pipeline, outreach, content + approvals, social, demos, tasks, my tasks, team, calendar, notes, activity, analytics, settings, co-overview).
- Shared logic and data helpers, shadcn UI component library, styles/design system.
- Auth integration (protected route gate, sign-in flow) wired to this project's own backend.

## Backend

The repo ships three database migrations (schema, policies, and later changes). Its `.env` points at the original project's backend, which this project cannot use.

- Enable Lovable Cloud on this project.
- Apply the three migrations in order to recreate the schema, grants, RLS policies, and any seeded rows.
- Regenerate the local backend client/types so they match the new backend. Old keys from the repo's `.env` are ignored.

Result: same app, clean database. Existing data from the original project is not copied.

## Technical notes

- Same stack (TanStack Start + React 19 + Tailwind v4 + shadcn), so files map 1:1 into `src/`.
- Dependencies added to match the repo: `@dnd-kit/*`, `@hookform/resolvers`, `react-hook-form`, `recharts`, `date-fns`, `cmdk`, `sonner`, `vaul`, `embla-carousel-react`, `input-otp`, `react-day-picker`, `react-resizable-panels`, `zod`, plus the Radix packages the UI components need.
- `src/routes/index.tsx` placeholder is replaced by the repo's index route; `src/routeTree.gen.ts` is regenerated by the router plugin rather than copied blindly.
- Head metadata (title/description/OG) is set per route with ElevateX-specific values.
- After import: install, typecheck, and load the auth page plus one authenticated page in the preview to confirm routing and data queries work.

## Out of scope

- Copying production data or connecting to the original backend.
- Feature changes or redesigns — this is a like-for-like import.
